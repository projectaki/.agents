# Task workspace

This directory contains one task. The source worktree is in repo/.
The task context is in context/. Each session owns one subdirectory.
The launch instructions identify the current session's context directory.

Read task.md if it exists. Otherwise, use the interactive assignment.
Read the project memory and relevant project context identified at launch.
Read repository instructions before working on source files.

Write findings in your own session directory.
Include evidence and distinguish verified facts from assumptions.
Keep the findings current after meaningful work.
Do not edit other sessions' findings.
Do not inspect sibling tasks.

Read relevant task findings before repeating work, unless the assignment
requires an independent investigation. During an independent investigation,
do not read other sessions' findings until the investigation finishes.

Only one session may edit the source worktree at a time.
I assign that responsibility manually.
Shared project memory and context also require one assigned editor at a time.
Keep task-specific details in this task's context.
