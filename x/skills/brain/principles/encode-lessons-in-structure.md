# Encode Lessons in Structure

When the same problem or the same review correction comes back in the code, turn the rule into a mechanism. Do not add more text, such as a convention in a document or a comment. Use a lint rule, a type, a runtime check, a test, or a script.

- If a mechanism can enforce the rule, use only the mechanism. A repeated instruction is a sign that a mechanism is missing.
- If the rule needs judgment and no mechanism can enforce it, make the rule easy to find, and add an example of the mistake.
