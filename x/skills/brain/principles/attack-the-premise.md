# Attack the Premise

When two or more fixes that depend on the same belief fail the same check, doubt the belief, not the fixes.

- Write the belief down: the one sentence that every failed fix assumed.
- Test the belief before the next fix. Find an observation that comes out differently if the belief is false, and make it. Look at the pattern of the failures, not only at their size.
- If the evidence contradicts the belief, look for what the failures have in common that the belief did not predict. If one part always ends up on the losing side, change what puts it there. Do not add a mechanism that cleans up after it.

Do not start the next fix before you write the belief down and test it.
